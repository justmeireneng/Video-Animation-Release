# Mascot pose placeholders

The approved `creator_01` identity remains in `references/character/character_reference.png`.
Until approved transparent pose assets are supplied, the Remotion loader maps every missing pose
(`idle`, `talking`, `explain`, `point_left`, `point_right`, `surprised`, `thinking`, `happy`)
back to that same reference image. Remotion adds only subtle motion and orientation; it does not
redesign the face, hair, outfit, proportions, or line style.
